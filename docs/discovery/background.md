# Alice background

Alice is a social/care robot associated with the VU Amsterdam SELEMCA programme led by Johan Hoorn and developed collaboratively with Elly Konijn and others. Institutional sources describe the goal as reducing loneliness and supporting independence among older adults. The documentary-era platform is described in academic sources as a Hanson/Robokind Alice R50 with an expressive face. Later descriptions of Alice 2.0 refer to combined Alice and Leolani software/research work and should not be assumed to mean identical hardware.
